    Getting Started.

    My First Workflow + Execution

    1. Install ayon-workflow addon in your local bundle
    2. Ensure your dependencies are updated (you can use ayon-dependencies-tool for that)
    3. Start AYON through the launcher.
    4. From AYON Console, copy/paste the following:
    from ayon_workflow.workflow_editor import Workflow
from ayon_workflow.workflow_execution import execute_workflow
from ayon_workflow.plugin_system import register_all_plugins

# Discover all available plugins (node types).
register_all_plugins()

# Create a new workflow.
my_first_workflow = Workflow(name="My First Workflow")

# Create a new node within the workflow execution graph.
my_graph = my_first_workflow.execution_graph
# NoOp = no operation (does nothing).
my_node = my_graph.create_node("NoOp")
# Set "hello world" as node input_data value
my_node["input_data"] = "hello world"

# Execute the workflow locally.
result = execute_workflow(my_first_workflow)
print(result)
    1. This should return you:
    {'NoOp1.output_data': 'hello world'}

    Which translates as: * The whole workflow has been executed. * The output of the node NoOp1 is "hello world"

    Congratulation you've just created and executed your first workflow.

    Glossary

    Editing: - Workflow: An editable Python object describing an execution Graph and multiple optional DispatchGraph. - Graph: An editable Python object describing a workflow execution. It is composed of multiple Node objects. - Node: A Python object representing a unit of work. It is instantiated from a Plugin description. A node’s inputs can be static values or dynamically connected to outputs of other Node objects. - Plugin: A Python dictionary defining the type and behavior of a Node. - DispatchGraph: A editable python object describing how to split a Workflow execution Graph. It is composed of AbstractDispatchTask.

    Execution: - Flow (taskflow): A non-editable Python object generated from a Graph, containing all Atom objects and their connections. - Task (taskflow): A dynamic class created from the Plugin description. Used by a Flow to instantiate Atom objects. - Atom (taskflow): A non-editable Python object inside a Flow, representing a Node, it instantiats a Task. - Backend (taskflow): A persistent component that stores Atom state, inputs, outputs, and Flow metadata, enabling split or distributed Flow execution. - Job (job description): A dataclass representing a job dispatched to a render manager (lightweight counterpart to OpenJobDescription.Job). - Step (job description): A dataclass representing a step within a Job, executed on a worker (lightweight counterpart to OpenJobDescription.Step).

    Visual Workflow Editor

    The ayon-workflow addon provides a UI to edit workflows. From the editor you can create/edit new workflow and load/save them as .json file.

    You can open it from the AYON tray menu.

    or via a CLI:

    $AYON_EXECUTABLE addon workflow editor
